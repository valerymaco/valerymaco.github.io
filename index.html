CC5. Accessing data: API

This chart has a live link to the World Bank API: the data is requested each time the page loads, so the chart updates itself when the World Bank publishes new figures.

  • Base URL: https://api.worldbank.org/v2/
  • Elements needed to call the data: after the base URL come the country (country/per, Peru's three-letter code), the indicator (indicator/NE.EXP.GNFS.ZS, exports of goods and services as % of GDP), and two parameters after the "?": format=json, because the API returns XML by default, and per_page=100, so every year since 1960 arrives on a single page (the default is 50).
  • Data returned: JSON, but not tidy. The response is a list with two parts: the first is metadata (page number, total observations, date of last update) and the second holds the observations. Each observation is one country-year, but "country" and "indicator" are nested objects (each with an "id" and a "value"), the year is stored as text, the most recent year comes first, and missing years appear as null. In the Vega-Lite spec I select the second part with "property": "1", drop the null values and convert the year to a number.
  • Full URL used: https://api.worldbank.org/v2/country/per/indicator/NE.EXP.GNFS.ZS?format=json&per_page=100
